Takasukai Interpreter v0.14

핵심 업데이트
1. 한국어 활용형 정규화 강화
   - 검토하다/검토하고/검토했습니다/검토하면서 같은 활용을 같은 의미로 탐지
   - 조사와 공손 종결어미를 일부 제거해 로컬 매칭률 향상

2. 긴 표현 우선 매칭
   - 단일 명사보다 '본인의 의사를 반영하다', '지역에 나가 활동하다' 같은 결합표현을 먼저 제시
   - 긴 표현 안에 포함된 짧은 일반 단어 중복을 억제

3. 의미개념 DB 추가
   - 한국어 표현이 DB 문구와 정확히 같지 않아도 의미군으로 연결
   - 복지/가족지원/지역사회/서비스/법인교류/통역/한국제도 중심 69개 개념군

4. 한국어→일본어 문법 DB 확대
   - 총 231개
   - 질문, 경어, 조건, 시간, 비교, 기관표현, 계획, 가능/필요, 인용/의견 등을 강화
   - 오른쪽에 최대 12개까지 표시하며 상위 5개는 '우선' 표시

5. 일본어 조립 순서
   - 한국어 원문에서 잡힌 단어/결합표현/문법을 원문 순서에 가깝게 배열
   - 왼쪽 '일본어 보조번역'에도 로컬 조립 힌트를 항상 유지
   - 예상문장 매칭이 실패해도 로컬 결과가 사라지지 않음

6. 예상문장 후보 개선
   - 문자열 유사도뿐 아니라 유연한 키워드/활용형 매칭을 반영
   - 예상문장은 보조 기능이고, 메인은 로컬 조립 엔진

Gemini는 v0.11과 동일하게 선택적 보강으로 유지됩니다.
API가 없어도 로컬 분석/조립은 작동합니다.

테스트 추천 문장
- 저희는 이용자 한 분 한 분의 특성에 맞춰서 필요한 경우 보호자와 정보를 공유하면서 지원하고 있습니다.
- 본인의 뜻을 최대한 확인하고 필요하면 지원 계획을 다시 검토합니다.
- 여기 이용하시는 분들은 보통 몇 년 정도 계속 이용할 수 있습니까?
- 직원들의 전문성을 높이기 위해 어떤 교육을 실시하고 있습니까?
- 한국과 일본은 명칭은 비슷하지만 제도적인 의미가 다른 부분도 있다고 생각합니다.


v0.14 주요 변경
- 한국어 입력의 단어/문법/조립 힌트를 점수순이 아니라 실제 발화 순서로 표시
- 조립 순서에서 겹치는 짧은 단어·문법을 억제하고 긴 표현을 우선
- 위치를 특정할 수 없는 fuzzy 의미 매칭은 단어 힌트에는 유지하지만 조립선에서는 제외
- 한국 복지기관 용어와 설명형 일본어 표현 추가
- 장애인종합복지관/직업재활시설/주간보호센터/장애어린이집 등은 일본 법정 서비스명으로 임의 치환하지 않도록 주의 데이터 추가
- 예시 기관소개 문장에 필요한 지역연계, 영유아 조기지원, 생애주기, 인천 최초 등의 표현 보강
- 완성 번역은 Gemini/예상문장 영역의 보조 기능으로 두고 로컬 메인은 말한 순서 조립으로 유지


[v0.14 핵심 변경]
- 로컬 문맥 번역팩 81개 추가: 정확 번역 / 쉬운 대체 / 공식 표현 / 제도주의를 뉘앙스와 함께 표시
- 기존 회화·통역 종합집 데이터를 로컬 일반어휘에 병합: 추가 313개, 총 1140개
- 의미 누락 점검: 현재 발화의 주요 내용어 중 로컬 DB가 강하게 연결하지 못한 항목을 표시
- 말한 순서 조립에 번역팩을 최우선 반영하고 하위 단어 중복 억제

- Gemini는 선택적 보강. 로컬 결과가 항상 우선 표시
