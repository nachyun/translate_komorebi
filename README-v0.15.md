# Takasukai Interpreter v0.15

Iroiro 예문 화면에서 착안한 문장 중심 통역 화면입니다.

- 일본어 원문과 한국어 의미를 한 카드에 표시합니다.
- 한자 위 후리가나는 기본 표시되며 `あ 후리가나`로 켜고 끕니다.
- 한국어 뜻 숨기기, 원문 복사, 큰 글씨, 일본어 원문 듣기를 지원합니다.
- 단어·문법 태그를 누르면 설명과 번역팩 대체 표현을 펼칩니다.
- 한국어 입력은 원문 아래에 일본어 조립 힌트를 원문 순서로 표시합니다.
- 의미 누락 가능 표현과 제도 차이 주의는 카드 아래에 표시합니다.
- 전체 분석과 음성인식 옵션은 펼쳐서 확인할 수 있습니다.
- `직접 입력 · 예문으로 살펴보기`에서 마이크나 API 없이 양방향을 시험할 수 있습니다.

## 실행

VS Code에서 이 폴더를 열고 Live Server 등 로컬 웹 서버로 `index.html`을 여세요.
HTML 파일을 더블클릭하는 file:// 방식은 JSON 데이터 로딩이 제한될 수 있습니다.
GitHub Pages에는 이 폴더 안의 파일들을 모두 함께 업로드합니다. 새로 추가된
`reader.css`, `reader.js`도 반드시 포함하세요. 상대 경로를 사용하므로 하위 저장소 경로에서도 동작합니다.

iPhone/iPad에서는 배포한 HTTPS 주소를 Safari로 엽니다.
음성인식은 기기의 브라우저 지원 및 마이크 권한이 필요합니다.
일본어 듣기는 기기에 설치된 음성을 사용하며, 재생 전에 녹음을 중지합니다.
재생 후 발언 버튼을 누르면 다시 녹음합니다.

## 후리가나와 번역 범위

기존 읽기 DB와 어휘 DB의 등록된 읽기를 사용합니다. 등록되지 않은 한자에는
임의로 읽기를 붙이지 않습니다. 고유명사·복수 독음은 문맥별 오독 가능성이 있어
확인이 필요합니다. 후리가나 숨김 상태에서도 복사되는 원문에는 읽기가 섞이지 않습니다.
로컬 문장 매칭 결과는 정확한 전체 번역을 보장하지 않으므로 카드의 매칭 표시를 확인하세요.
Gemini는 기존과 같이 선택적 보강이며 직접 입력 예문은 자동 AI 호출 없이 로컬로 분석됩니다.
